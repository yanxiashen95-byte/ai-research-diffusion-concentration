## Web of Science search and data retrieval

### 1. Database and search query

Bibliographic records were retrieved from the **Web of Science Core Collection (WoS)**.  
The search was conducted in the **Topic (`TS`) field**, which covers titles, abstracts, author keywords, and Keywords Plus.

The complete AI-related search query used in this study is provided in
[`search_strategy/WoS_AI_search_query.txt`](search_strategy/WoS_AI_search_query.txt).

The search results were restricted to:

- Publication years: **1990–2025**
- Document types: **Article** and **Review**
- Language: **English**
